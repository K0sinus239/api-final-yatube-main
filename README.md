
### Описание:

Учебный проект по API в DRF студента Белова К.А.

### Установка:

Клонировать репозиторий и перейти в него в командной строке

Cоздать и активировать виртуальное окружение:

```
python -m venv venv
```

```
source env/Scripts/activate
```

Установить зависимости из файла requirements.txt:

```
python -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python manage.py migrate
```

Запустить проект:

```
python3 manage.py runserver
```

### Пример использования:

Перейдите по ссылке с документацией http://127.0.0.1:8000/redoc/

Попробуйте поотправлять запросы на указанные эндпоинты (не забудьте авторизироваться и получить токен)
